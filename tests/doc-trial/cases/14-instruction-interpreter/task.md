Write a single file `main.wf` with entry `main`.

Implement an instruction machine with an unsigned 64-bit accumulator, initially zero, an unsigned 64-bit counter supplied when execution starts, and these four operations: add an unsigned literal to the accumulator; decrement the counter; jump to a supplied zero-based instruction position if the counter is nonzero, otherwise advance; halt and return the accumulator. Addition and decrement wrap modulo 2 to the power 64. Execution begins at instruction zero. Adding or decrementing advances to the next instruction. An empty instruction sequence or any attempted transition outside the sequence returns zero.

Run the four-instruction sequence that adds three, decrements the counter, jumps to instruction zero while the counter is nonzero, and then halts, starting with counter one thousand. Publish the actual returned accumulator as exactly eight little-endian bytes on standard output. The expected accumulator is 3000, whose bytes are b8 0b 00 00 00 00 00 00. Finish partial output transfers until all eight bytes are published. Return status zero if the returned accumulator is 3000, one if it differs, or two on an output error. Write nothing else to standard output or standard error. Use the supplied process and IO interfaces for startup and byte output; close the startup directory permissions. No arguments or input are required. Implement and run the instruction machine rather than directly emitting its expected result.
