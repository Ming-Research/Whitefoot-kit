Provide reusable pairs and optional choices for unsigned bytes and signed 64-bit integers. Construct a pair with both fields equal to 7 and a signed pair with both fields equal to -9. Construct present choices containing 3 and -5. Exercise checked additions 1 + 2 as unsigned bytes, 255 + 1 as unsigned bytes (which must report overflow), and -4 + 9 as signed 64-bit integers. Recover an optional byte 19 inside a reusable wrapper. Recover the second byte of an owned two-byte packet containing 11, 11 after it has been held inside a generic owner that may be discarded. Verify these observations.

Write nine eight-byte words in this order: the byte pair's left field (7), the signed pair's right field (-9), the two present choice values (3, -5), the successful byte sum (3), an overflow marker (1), the signed sum (5), the recovered optional byte (19), and the recovered packet byte (11). Signed values use 64-bit two's-complement encoding; all words are little-endian. Stdout is exactly 72 bytes. Return status 1 for any failed observation or unexpected arithmetic result.

Write a single file `main.wf` with entry `main`. Use the standard process, filesystem, IO and time interfaces for startup and byte output. On successful computation and output, exit with status 0. If stdout publication fails, exit with status 250. Write exactly the bytes specified, with no text, separators or trailing newline.
