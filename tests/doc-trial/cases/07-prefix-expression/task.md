Parse a prefix-expression byte sequence whose expressions are single decimal digits or a plus sign followed by two expressions. Successful parsing returns the expression and the next unread byte position. Report truncated input separately from an invalid token. Evaluate successful expressions using checked unsigned 64-bit addition that reports overflow.

Parse the ASCII bytes +2+34 from position zero, verify that parsing consumes all five bytes, and verify that evaluating the result gives 9. Parse the incomplete ASCII bytes +2 from position zero and observe the resulting error. Write three eight-byte unsigned little-endian words: the computed next unread position (5), the computed evaluated value (9), and the incomplete-input error marker (1 for truncated input, 2 for invalid token). The correct marker for this input is 1. Stdout is exactly 24 bytes. Return status 1 if successful parsing/evaluation has an unexpected result, evaluation reports overflow, or the incomplete expression is accepted.

Write a single file `main.wf` with entry `main`. Use the standard process, filesystem, IO and time interfaces for startup and byte output. On successful computation and output, exit with status 0. If stdout publication fails, exit with status 250. Write exactly the bytes specified, with no text, separators or trailing newline.
