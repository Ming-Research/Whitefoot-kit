Create a byte-keyed unsigned 64-bit integer table using the one-byte names a and b. Store 17 under a, retrieve it twice in separate whole-table atomic operations, replace it with 23 through entry-scoped atomic access, and retrieve the replacement through another whole-table operation. Each operation must finish before the next begins. Verify that b remains absent. Form both keys as ranges over the same constant two-byte array; key identity is its byte content.

Write the two first retrieved values, the replacement value, and the absent-key tag zero, in that order. Each occupies eight little-endian bytes as an unsigned 64-bit integer, giving exactly 32 stdout bytes containing 17, 17, 23, 0. A missing expected entry, an incorrect value, or a present b must fail with a nonzero status.

Write a single file `main.wf` with entry `main`. Use the standard process, filesystem, IO and time interfaces for startup and byte output. Destructure all startup fields and close both startup directory permissions. On successful computation and output, exit with status 0; if stdout publication fails, exit with status 250. Write exactly the bytes specified, with no text, separators or trailing newline.
