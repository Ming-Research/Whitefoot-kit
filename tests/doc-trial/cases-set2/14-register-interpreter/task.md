Write a single file `main.wf` with entry `main`. Implement a register/frame instruction interpreter over boxed runtime-capacity instruction and unsigned 64-bit register storage. An instruction is a struct containing an unsigned-byte kind, two unsigned-byte register offsets a and b, and an unsigned 64-bit target. Start at instruction zero with a supplied frame base. Publish preconditions requiring a nonempty instruction sequence, the initial base at most the supplied room, and at least room plus 256 registers. Guarantee that interpretation preserves the register-storage length. Keep loop invariants for the instruction position and frame bound.

Kind zero returns the register at base plus a. Kind one changes both the instruction position and frame base to target; return zero if target is outside the instruction sequence or greater than room. Every other kind copies the register at base plus b to base plus a and advances one instruction; return zero if the next instruction is outside the sequence. Preserve the frame bound through paths that change only the instruction position, without a redundant runtime recheck of that invariant. Dispatch with comparisons on the instruction's kind.

Use four instructions and 260 initially zero registers. Set register 1 to 77 and register 3 to 99. With base zero and room four, execute these instructions in order: kind 2 copying offset 1 to offset 0; kind 1 targeting instruction/frame 2; kind 255 copying offset 1 to offset 0; kind 0 returning offset 0. Record the returned value and registers 0 and 2: 99, 77 and 99.

Then reuse the storage for four further runs, recording their return values. First replace instruction zero with a jump to 4, retaining base zero and room four: return zero. Next change that jump target to 2 and use room one: return zero. Next restore the original first instruction, replace the last instruction with kind 2 copying offset 1 to offset 0, and use base zero and room four: falling past the end returns zero. Finally replace instruction zero with kind 0 returning offset 1, start at base two with room four, and return 99.

Write all seven computed observations, in the stated order, as unsigned 64-bit little-endian values: exactly 56 bytes, with no text, separators or newline. Use the standard process, filesystem, IO and time interfaces, close both startup directory permissions, and handle partial stdout writes. Return zero after publication or 250 on output failure.
