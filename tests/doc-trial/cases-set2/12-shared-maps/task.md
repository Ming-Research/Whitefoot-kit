Write a single file `main.wf` with entry `main`. Use a shared concurrent hash map and separate shared total and mismatch counters. Its eight byte-string keys are the nonempty prefixes of abcdefgh, in shortest-first order. Start empty. Eight concurrent writers each increment every key two thousand times, updating the accompanying total in the same atomic statement. Two concurrent observers each compare the sum of all eight entries with that total three hundred times, recording every mismatch. Use entry targets for writers, a KeySet target for observers, and whole-map targets for final inspection and counting. Join all activities before final inspection.

Every key must contain 16000, the map must hold eight entries, the total must be 128000, and the mismatch count must be zero. Delete the shortest key by assigning an absent entry; seven entries must remain. Return 1 for a wrong initial entry count, 2 for a wrong or absent entry value, 3 for a wrong remaining count, 4 for a wrong total, and 5 for any observer mismatch.

After these checks, write twelve unsigned 64-bit values in little-endian byte order: the eight computed entry values in shortest-key-first order, the initial entry count, the total, the mismatch count, and the remaining entry count. This is exactly 96 bytes, with no text, separators or newline. Use the standard process, filesystem, IO and time interfaces, close both startup directory permissions, handle partial stdout writes, and return zero after publication or 250 on publication failure. The environment requests four IO drivers.
