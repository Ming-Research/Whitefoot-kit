Provide generic fixed-capacity circular-storage helpers for filling all slots with copies of a value, filling all slots with absent options, removing an indexed value by last-value replacement, conditional insertion at the back, conditional removal from the back, and transfer into fresh empty storage while preserving logical order. Publish checked entry and exit guarantees for the length and capacity relationships. The filling operation requires a copy bound; the other helpers accept droppable element types. Removal requires at least one later value to replace the selected value. Transfer uses loop invariants accounting for remaining source values, produced destination values, and destination capacity. No quantified range contract is required.

With capacity four, observe four vacant options and four filled bytes equal to 7. Attempt to append 8 to the full filled sequence: require its return and preserve length four. Removing from a separate empty sequence returns absence. Start a third sequence with 21,22,23; remove index zero, obtaining 21 and leaving 23,22. Conditionally append 24 and then take it back; the length goes from two to three and back to two. Form another capacity-four sequence with 10,11,12,13, remove its first two values, append 14 so its occupied slots wrap past the physical end, and transfer it into fresh empty storage. Require logical order 12,13,14, length three, and origin zero.

Write twenty computed observations in this order: vacant length, filled length, filled first byte, filled last byte, full insertion's returned value, length after refusal, empty-removal absence tag, indexed removal value, length after indexed removal, remaining first value, remaining last value, successful-insertion absence tag, length after insertion, back-removal value, length after back removal, rebased length, rebased origin, and the three rebased values. Absence tags are zero. Encode each as eight little-endian bytes of an unsigned 64-bit integer, giving exactly 160 stdout bytes containing 4,4,7,7,8,4,0,21,2,23,22,0,3,24,2,3,0,12,13,14.

Write a single file `main.wf` with entry `main`. Use the standard process, filesystem, IO and time interfaces for startup and byte output. Destructure every startup field and close both startup directory permissions. On successful computation and output, exit with status 0; failed boundary/rebase checks exit nonzero, and stdout publication failure exits with status 250. Write exactly the bytes specified, with no text, separators or trailing newline.
