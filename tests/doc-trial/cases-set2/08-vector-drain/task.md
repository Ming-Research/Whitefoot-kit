Use the standard vector collection through its published standard-library interface, and define a binding for its consuming callback interface. The callback records a count, a sum, and a base-257 fold in a caller-owned environment. Each consumed unsigned 64-bit value changes the fold to the old fold times 257 plus that value, using wrapping arithmetic.

Create an empty vector with ceiling eight, drain it while empty, and reserve space for eight. Append 1,2,3,4,5 and truncate to the first two values: ordered consumption of 3,4,5 must produce fold 199180 and count 3, retaining 1,2 and the reserved capacity. Append 6, remove index zero by replacement from the last value (returning 1), then remove index one (returning 2). Reset only the fold and count, drain the remaining value, drain the empty vector again, reuse it by appending 7, truncate first to one and then zero: fold 1549 and count 2 must result. Reset only the fold and count again; refill with 1 through 8, truncate first to seven and then six: fold 2063 and count 2 must result. Preserve the six remaining values in order and the original reserved capacity; drain them and free the empty vector. The final count must be eight.

Write these thirteen computed observations, in order: first fold, first count, first retained value, second retained value, initial reserved capacity, first removal, second removal, reuse fold, reuse count, repeated-truncation fold, repeated-truncation count, final reserved capacity, final consumed count. Each occupies eight little-endian bytes as an unsigned 64-bit integer, giving exactly 104 stdout bytes: 199180,3,1,2,8,1,2,1549,2,2063,2,8,8. A failed check must exit nonzero.

Write a single file `main.wf` with entry `main`; use aliases for the standard vector functions and callback interface. Use the standard process, filesystem, IO and time interfaces for startup and byte output. Destructure every startup field and close both startup directory permissions. On successful computation and output, exit with status 0; if stdout publication fails, exit with status 250. Write exactly the bytes specified, with no text, separators or trailing newline.
