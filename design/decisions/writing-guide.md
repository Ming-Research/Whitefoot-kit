# The writing guide

What the writing guide, docs/writing.md, says about specification changes that the newest Whitefoot release does not yet hold.

### decision guide-follows-newest-release
For a specification change the newest release does not yet hold, the guide gives that release's form first, then the new rule marked with the release, and no example the release cannot check.
- rejected: an agent proposed asking the owner to start a compiler release of Whitefoot's main so that these entries carry compiled examples; the owner rejected it, because the owner gave no reason.
